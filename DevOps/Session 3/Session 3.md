
# Shell Introduction
#shell_introduction
- Shell is text-based tool for communicating between User & Kernel
## Various types of shells available
 - Bourne Shell (sh)
 - Bourne-Again Shell (Bash)
 - C Shell (csh)
 - Z Shell (zsh)
