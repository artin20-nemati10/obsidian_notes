
# Shell Introduction
#shell_introduction
- Shell is text-based tool for communicating between User & Kernel
## Various types of shells available
 - Bourne Shell (sh)
 - Bourne-Again Shell (Bash)
 - C Shell (csh)
 - Z Shell (zsh)
# Commands
#session3commands

|      **Command**      |             **Work**             |
| :-------------------: | :------------------------------: |
| **ip address (ip a)** |           *IP Address*           |
|    **echo $SHELL**    |           *Shell Type*           |
|   **cd /Directory**   |  *switch between the directory*  |
|        **pwd**        |    *shows current Directory*     |
|        **ls**         | *files in the current directory* |
|       **ls -l**       |     *Just more information*      |
|       **cd ..**       |   *Back to previous directory*   |
|       **ls -h**       |     *Make it Human-Readable*     |
